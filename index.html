Генератор 3D-моделей

Процедурный генератор WolF собирает модель из геометрических форм по вашему описанию и палитре, прямо в браузере, без серверов. Это не нейросеть, а конструктор по теме — для готовых реалистичных моделей из фото лучше подойдут специализированные сервисы.

Kokoro — нейросеть, работает прямо в браузере без ключей и регистрации. Качество выше, файл WAV скачивается. Лучше для английского, до 1000 символов за раз.
Системные голоса — голоса вашего устройства (на Windows есть русские). Прослушать можно везде. Сохранить файл можно только в приложении для ПК.

Локальный ИИ (без интернета и ключей)

Нейросеть запускается прямо в браузере на видеокарте. Скачивается один раз и остаётся в браузере. Нужен свежий Chrome или Edge на компьютере. Картинки локальная модель не видит.
